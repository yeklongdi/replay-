# 回放工坊

回放工坊（Replay Studio）是一个 Windows 跑团回放编辑器。导入 TXT、DOCX 或 DOC 日志后，可以在时间线上编辑台词和角色、添加配音与剪辑素材，导出 1080p、30 帧的 MP4。工程可以打包成 `.replay` 文件交给团友续编。

## 下载与使用便携版（Windows）

无需安装 Python 或配置环境，直接下载便携版即可使用（已内置中文字体、预览音频组件与 FFmpeg 导出编码器）：

1. 打开本仓库的 [Releases 发布页](https://github.com/yeklongdi/replay-/releases/latest)。
2. 在页面下方的 **Assets** 附件列表中，点击下载 **`ReplayStudio-Windows-x64.zip`**。
3. 将压缩包**完整解压**到任意文件夹（注意：不要直接在压缩包预览窗口里双击运行，请把 `ReplayStudio.exe` 与同目录的 `_internal` 文件夹放在一起）。
4. 双击解压后的 **`ReplayStudio.exe`** 即可启动。
5. 后续有新版本时，无需重新找网页，直接在软件左上角点 **「设置 ▾ → 检查更新」** 即可一键下载校验并自动替换重启。

### 快速上手

1. 在左上角「设置」中选择「导入日志」，或把 UTF-8 TXT、DOCX、DOC 跑团日志拖到窗口。已兼容海豹着色器（`log.weizaima.com`）导出的全部格式与筛选开关组合；按 `.log off` 自动分场或按日期筛选。点击左侧台词可跳到预览，下拉框可按角色、日志日期或场次筛选。
2. 在右侧修改正文和时长，选择多条时可批量分配角色。用左侧按钮隐藏、恢复或移动所选消息。要拆分一条，先把光标放到正文里，再点「按光标拆分」。
3. 在「台词」工作台给角色添加立绘。在模板页可拖动元素，也可拖动元素右下角缩放。
4. 在「设置」中选择「保存」或「打包工程」得到 `.replay` 文件。工程包带整份原始日志、已编辑的时间线和素材，团友可以直接打开续编。
5. 在「设置」中选择「导出 MP4」导出整集。导出片段时，用「标记起点」和「标记终点」记录当前帧，可先点「播放选段」核对。选中进度条后可用左右方向键逐帧微调。

「设置」里的界面色调可选青绿、冷蓝灰或暖灰，色调设置会在下次打开软件时恢复。菜单底部提供手动「检查更新」，点击后从 GitHub Releases 检查最新版本，并在便携版中一键下载、校验 SHA-256、替换并重启进入新版本（启动软件不会自动联网检查）。

## 支持的日志格式

兼容海豹着色器（`log.weizaima.com`）的全部导出格式与显示开关组合（时间显示过滤、年月日不展示、平台帐号隐藏、表情图片过滤等）：

1. **原始 TXT 日志**（`下载原始文件`）：消息头包含昵称、账号和日期时间，正文从下一行开始。

```text
主持人(10001) 2026/11/22 20:18:09
旧门缓缓打开。

守卫(10002) 2026/11/22 20:18:12
“谁在那里？”
```

2. **DOCX / DOC 日志**（`下载docx`、`下载带图doc`、`下载对话doc`）：
   - 支持只显示时分秒、显示完整年月日、隐藏时间、显示或隐藏平台账号，以及两栏对话表格。
   - 若直接另存为 Word 文档，请使用 `.docx` 格式；支持读取带图或对话形式的网页归档 `.doc`（不支持旧版二进制 `.doc`）。

```text
20:18:09 <主持人>: 旧门缓缓打开。
2026/11/22 20:18:12 <守卫(10002)>: “谁在那里？”
```

3. **文本导出格式**（保存为 UTF-8 `.txt` 即可导入）：
   - **论坛代码**（单行 BBCode，兼容颜色名、十六进制色值与次行空格缩进）与 **论坛代码(内容多行)**。
   - **回声工坊**（`[角色]:内容`、`[主持人,KP]:内容`、`# [骰娘]:内容` 及 `{*}` 语音合成标记）。

## 剪辑背景、配乐与音效

1. 切到左上角「剪辑」。从左侧导入 PNG、JPG、MP3 或 WAV，把素材拖到下方对应轨道。可重复拖放同一素材，也可添加配乐轨和音效轨；单击左侧轨道名可选中并上下拖动调整顺序，右键轨道名可改名、复制、上下移动或删除音轨。
2. 拖动片段调整开始时间，拉两端裁切。右侧可精确输入起点和时长，并设置音频文件起点、音量和循环。重叠的音乐与音效会一起播放。
3. 单击时间尺可以精确定位，单击台词块可跳到该条台词的开头。在播放头处添加书签后，可从右侧「书签管理」单击跳转（右键可改名或删除），也可在轨道上双击书签改名。选段按钮在「剪辑」页位于下方轨道工具栏，用 Ctrl + 滚轮缩放，Shift + 滚轮横向滚动，或用工具栏适应整集。
4. 片段可固定在成片时间，也可跟随指定台词。隐藏绑定的台词后，片段标为「待定位」并暂时跳过。恢复台词即可恢复播放，也可在右侧重新绑定。

## 声音与角色配音

1. 切到左上角「声音」。左侧选择任意角色或「（旁白）」，在右侧「角色声音」选择发声方式：
   - **静音**：不发声，适合骰娘、系统提示或纯字幕角色。
   - **UT 音效**：完全离线、零硬件负担的对话节奏音效（内置多种预设，支持调音高/节奏/音量或导入本地短音效）。
   - **AI 人声**：默认内置免费的 Edge-TTS 现成中文与方言人声，联网即可试听或按角色/整集增量生成，命中缓存不重复合成。
2. 点击「API 接口…」或「配置 API…」可打开自定义语音接口窗口，支持接入本机或云端部署的 GPT-SoVITS (`api_v2`)、OpenAI 兼容 (`/v1/audio/speech`) 或通用 HTTP JSON 语音服务。接口地址和密钥仅保存在本机，不会写入分享给团友的 `.replay` 工程包。
3. 在左侧可开关「跳过骰点指令」「说话时压低配乐（BGM 闪避）」「配音自动延长台词时长」以及「括号内容」朗读策略。在右侧「本句微调」可为单条台词改口播读音（不改字幕）、单句静音或导入本地干声替换。

旧工程打开时，场景背景和循环配乐会转为原时段的片段，场景名会转为书签。保存后，剪辑轨道、声音配置和素材库会一并写入工程包。

## 从源码运行和构建

在项目目录用 Python 3.12 安装依赖。源码运行时从 PATH 寻找 FFmpeg，也可用 `REPLAY_FFMPEG` 指向指定的 ffmpeg.exe。

```powershell
python -m pip install -r requirements.txt
python app.py
```

构建脚本把运行库和编码器一起打进便携包，同时生成 `SHA256SUMS.txt` 校验文件。

```powershell
python -m pip install PyInstaller==6.21.0 imageio-ffmpeg==0.6.0
.\build.ps1
```

需要发布新版本到 GitHub Releases（让便携版软件通过「设置 → 检查更新」直接获取）时，可用一键发版脚本自动改版本号、跑测试、打包并上传（需本机已登录 `gh` CLI）：

```powershell
.\release.ps1 -Version 1.1.0 -Notes "更新说明"
```

运行验收测试前，将 FFmpeg 和 ffprobe 加入 PATH。测试自带示例数据。项目上一级存有本地完整样本 `测试 跑团log.txt` 时，还会运行该样本的导入验收。

```powershell
python -m unittest discover -s tests -v
```
